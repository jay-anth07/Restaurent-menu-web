🌶️ Dakshin Delights - Restaurant Menu Application

A modern, responsive, single-page web application for a South Indian restaurant. This project features a visually appealing user interface with dynamic category filtering, search functionality, and a fully interactive slide-out shopping cart.

✨ Features

Dynamic Filtering: Users can filter menu items by categories: All, Pure Veg, Non-Veg, and Tiffins.

Live Search: Instant search functionality to find specific dishes by name or description.

Interactive Shopping Cart:

Add items to the cart with a single click.

Real-time cart counter in the navigation bar.

Slide-out sidebar to view the cart, adjust quantities (increase/decrease), or remove items.

Dynamic subtotal calculation.

Responsive Design: Fully mobile-friendly layout that adapts perfectly to phones, tablets, and desktop screens using Tailwind CSS.

Custom Image Mapping: 30 specific items are mapped to high-quality local images, while the remaining 30 dynamically generate clean, categorized placeholder images.

Toast Notifications: Smooth pop-up alerts when items are added to the cart or an order is placed.

🛠️ Technologies Used

HTML5: Standard markup for the application structure.

Tailwind CSS (CDN): For rapid, modern, and responsive UI styling.

jQuery (CDN): For DOM manipulation, event handling, cart logic, and filtering.

FontAwesome (CDN): For beautiful vector icons (cart, search, leaf, etc.).

🚀 Getting Started

Prerequisites

No complex build tools or package managers (like npm) are required. All you need is a web browser.

Installation & Setup

Clone the repository (or download the ZIP file):

git clone git clone https://github.com/jay-anth07/Restaurent-menu-web.git


Image Placement (Crucial Step):
Ensure all of your .jpg, .jpeg, and .webp food images (e.g., Avial.webp, Dosa.jpg, Chicken 65.jpg) are placed in the exact same root folder as the index.html file.

Run the Application:
Simply double-click the index.html file to open it in your default web browser. No local server is strictly required, though you can use VS Code's "Live Server" extension for the best development experience.

📁 Project Structure

Since this is a lightweight, single-page application, all HTML, CSS, JavaScript logic, and mock JSON data are contained efficiently within a single file to make deployment and hosting incredibly easy.
